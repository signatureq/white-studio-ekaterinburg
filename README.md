# White Studio Detailing

[Открыть сайт](https://signatureq.github.io/white-studio-ekaterinburg/)

Адаптивный сайт студии детейлинга в Екатеринбурге на HTML, CSS и JavaScript. Отдельный каталог из 12 услуг, страницы услуг и четыре фотоальбома автомобилей. Все изображения, шрифт и стили размещены локально.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` сохраняет статические файлы без обработки Jekyll. Изменения сайта загружаются обычным `git push`.

## Локальный просмотр

```sh
python3 -m http.server 4173
```

Открыть http://localhost:4173/.

## Контакты и заявки

Контактные данные студии можно добавить в `config.js`. Пока форма создаёт текстовый черновик локально. Отправку заявок необходимо подключить отдельно после согласования контактов.

Шрифт Manrope распространяется по SIL OFL; лицензия находится в `assets/OFL-Manrope.txt`.
